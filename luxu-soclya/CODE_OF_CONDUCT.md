# Código de conducta

Luxu existe para que las comunidades sean más seguras y agradables. Este proyecto también debe serlo.

## Compromiso

Quienes participan en este proyecto se comprometen a tratar a todas las personas con respeto, sin importar su edad, origen, identidad, orientación, capacidad o experiencia.

## Lo que se espera

- Lenguaje respetuoso y constructivo, también en las discusiones técnicas.
- Críticas al código y a las decisiones, nunca a las personas.
- Aceptar que otras personas tengan otras prioridades y otra forma de trabajar.

## Lo que no se tolera

- Insultos, palabrotas dirigidas, acoso, amenazas o discriminación.
- Publicar datos personales de otras personas sin su permiso.
- Usar el proyecto para atacar comunidades o para causar daño.

## Aplicación

Los mantenedores pueden borrar comentarios, bloquear a quien incumpla estas normas y retirar contribuciones que no respeten el espíritu del proyecto.

Para informar de un problema, abre un issue privado o contacta con los mantenedores por el canal que figure en el perfil del repositorio.

Este código se inspira en el [Contributor Covenant](https://www.contributor-covenant.org/es/version/2/1/code_of_conduct/) 2.1.
